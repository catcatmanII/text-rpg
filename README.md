# Text RPG

一個以手機瀏覽器為優先的繁體中文純文字 RPG 原型。

## 目前功能

- 玩家等級、HP、金幣與所在地狀態
- 背包
- 村莊與野外移動
- 隨機探索事件
- 哥布林戰鬥與逃跑
- 瀏覽器 localStorage 自動存檔
- 手機友善的單頁介面

## 執行方式

直接以瀏覽器開啟 `index.html` 即可執行。

## 設計方向

遊戲規則與狀態由 Game Runtime 管理，敘事層不直接決定 HP、金錢、物品等遊戲資料。未來可加入 LLM，負責理解玩家自由文字輸入、NPC 對話與自然語言敘事，再由 Runtime 驗證並執行實際遊戲行為。
